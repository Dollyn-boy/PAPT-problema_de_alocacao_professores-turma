# Referências e versões arquivadas

Esta pasta contém materiais preservados para rastreabilidade, não para execução automática.

- `modelagem_gapuefs.pdf` e `modelagem_gapuefs_versao_alternativa.pdf`: documentos de modelagem recebidos.
- `example_orientadora.jl`: exemplo da orientadora, referente a outro problema.
- `PAPT_JuMP_instancia_reduzida.jl` e `PAPT_JuMP_json_integracao_versao_anterior.jl`: versões anteriores do código de referência.
- `papt_instancia_reduzida_original.lp`: LP de uma versão reduzida antiga.
- `instancia_de_referencia_recebida.json`: instância enviada originalmente, preservada sem correções para auditoria.
- `reduzida_base_legada.json`: instância reduzida usada em um pacote anterior; não é a instância canônica atual.
- `ofertas_estruturadas_original.json` e `texto_bruto_original.txt`: resultados gerados pelo pipeline antigo, preservados para comparação.

A instância canônica que deve ser usada nos testes atuais está em `../projeto_ic/model_ic/instancias/referencia_v001.json`. As alterações nela são documentadas no README da raiz do projeto.
